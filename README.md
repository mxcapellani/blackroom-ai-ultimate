
# BLACKROOM AI ULTIMATE

### Cinematic & Editorial Visual Prompt Director

**Version 2.1.0**

A professional AI Skill for creating photorealistic, cinematic, fashion editorial and visually sophisticated image-generation prompts.

Designed for creators, photographers, fashion designers, visual artists and AI image-generation workflows.

## Features

### 1. Create image prompts
Transform short creative ideas into fully developed professional image prompts.

### 2. Image-to-prompt analysis
Upload a reference photograph and reconstruct its visible visual direction, including composition, wardrobe, environment, lighting, color palette and estimated optical characteristics.

### 3. Visual transformation
Reimagine an existing image in a new artistic direction while preserving explicitly requested attributes.

### 4. Fashion editorial direction
Create luxury fashion, beauty, experimental editorial, studio and architectural imagery.

### 5. Cinematic photography
Apply coherent lighting, photographic optics, environmental depth and expressive visual storytelling.

### 6. Photorealistic detail
Prioritize authentic skin texture, realistic fabric behavior, credible reflections and natural material response.

### 7. Campaign consistency
Develop coherent visual series with stable character, wardrobe, environment and art-direction anchors.

### 8. Generator adaptation
Adapt natural-language image prompts for supported platforms, including ChatGPT image generation, Midjourney, FLUX, Stable Diffusion environments and Ideogram.

### 9. Prompt refinement
Improve existing prompts while maintaining the original concept.

### 10. Advanced visual diagnostics
Identify contradictory instructions, poor camera logic, weak visual hierarchy and unrealistic material descriptions.

## Installation

The main Skill file is:

`SKILL.md`

This is a self-contained Agent Skill.

For repository-based Codex discovery, place the same file at:

`.agents/skills/blackroom-ai-ultimate/SKILL.md`

You can also import the Skill into compatible systems supporting the Agent Skills format.

Availability and installation methods depend on the host application.

## Example commands

### Create an editorial
"Create a luxury fashion editorial with a brutalist concrete environment, red backdrop, black tailored wardrobe and dramatic cinematic lighting."

### Analyze an image
"Analyze my uploaded reference image and reconstruct a complete English prompt describing its composition, subject, lighting, wardrobe, colors and textures."

### Transform a reference
"Preserve the subject's pose and wardrobe, but transform the scene into a high-fashion cinematic studio editorial."

### Create a campaign
"Generate five visually consistent editorial prompts with the same character, clothing, lighting direction and overall color palette."

### Improve a prompt
"Refine this prompt with professional photographic details and stronger cinematic composition."

## Recommended conversation starters

1. Create a cinematic photorealistic prompt from my idea.
2. Analyze my uploaded image and reconstruct its complete prompt.
3. Transform my reference image into a premium fashion editorial.

These are suggested starters for a custom GPT interface, not automatic buttons provided by a standalone Skill.

## Important limitations

Image reading requires multimodal image input in the host application.

Actual image rendering requires a compatible image-generation tool.

Specific camera metadata cannot reliably be inferred from a reference image alone.

Generated image similarity and character consistency vary by model.

This Skill is an independently authored implementation and not an export of a proprietary or inaccessible internal configuration.
